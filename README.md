# YouTube Video Summarizer using Google Gemini Pro

A simple end-to-end Generative AI application that converts YouTube video transcripts into concise, structured notes using **Google Gemini Pro** and **Streamlit**.

This project focuses on understanding prompt-based LLM usage, API integration, and building a clean UI for content summarization.

---

## 🚀 Features
- Extracts transcripts from YouTube videos (if captions are available)
- Summarizes long video content into clear bullet-point notes
- Uses Google Gemini Pro for text generation
- Simple and interactive Streamlit interface
- Secure API key handling using environment variables

---

## 🛠 Tech Stack
- **Python**
- **Streamlit**
- **Google Gemini Pro (Generative AI)**
- **YouTube Transcript API**
- **python-dotenv**

---

## 🧠 What I Learned
- How to integrate Google Gemini Pro using APIs
- Prompt design for summarization tasks
- Extracting and preprocessing YouTube transcripts
- Building lightweight GenAI applications with Streamlit
- Secure handling of API keys using `.env` files
